# ICSS Exam Question Pool

*Introduction to Computing for the Social Sciences (theory) · Prof. Dr. David
Garcia · Uni Konstanz*

This folder is the question bank for the written exam. It collects **every
question used in a past ICSS exam** (2023, 2024, 2025) plus **every exercise from
the 2026 theory exercise sheets**, indexed so that an exam can be assembled from
it in a few minutes with known topic and point coverage.

**93 items** across six files, one per exam question. Each carries a full worked
solution and marking notes; every numeric answer has been recomputed from
scratch, not copied from the source paper.

## Item format

Every item has a stable ID, a point value **as used in the source exam**, and a
solution. IDs never change once assigned, so an item can be referred to in notes
about which cohort saw which question.

```
## IC-04 · IEEE 754 multiplication · 4 pts · [2024-E1 Q1a, 2024-E2 Q1b, 2025-Ex Q1a]
<question text>
**Solution.** …
**Notes.** …
```

The bracketed tags say where an item has been used:

| Tag | Exam |
|---|---|
| `2023-Ex` | 2023/24 exam example |
| `2023-E1` | 2023/24 final exam (21.02.2024) |
| `2023-E2` | 2023/24 repetition exam (19.03.2024) |
| `2024-Ex` | 2024/25 exam example |
| `2024-E1` | 2024/25 final exam (17.02.2025) |
| `2024-E2` | 2024/25 final exam 2 (26.03.2025) |
| `2025-Ex` | 2025/26 exam example |
| `2025-E1` | 2025/26 final exam (16.02.2026) |
| `2025-E2` | 2025/26 resit exam (31.03.2026) |
| `TE-NN` | 2026 theory exercise sheet NN (see `../TheoryExercises/`) |
| `new` | Written for this pool; never yet used in an exam |

**Reuse warning.** An item tagged with an exam year has been seen by that
cohort, and past exams circulate. Items marked `new` or drawn from `TE-NN`
additional-practice sections are the safest choices for a fresh exam;
`Blueprint.md` explains the rotation.

## Errata found while building this pool

These are mistakes in past exam papers, listed so they are not copied forward.
Each is also flagged at the item itself.

1. **2025-E1 Q1a** asks to "convert 1012₈ to octal notation", the number is
   already octal. Presumably a base subscript was lost in editing. Fixed in
   `IC-01`, which uses an unambiguous set.
2. **2023-E2 Q2a** gives the array `10 33 19 26 27 28 31 34 35 42 44` for a
   binary search trace, but the array is **not sorted** (33 precedes 19). Binary
   search is undefined on unsorted input. `DS-06` uses the sorted array.
3. **2025-E1 Q6** and **2024-E2 Q6** both label two different subquestions with
   the same letter (`b` then `d`, and `c` then `c`). Cosmetic, but it confuses
   students when they write answers.
4. **2023-Ex Q4** jumps from subquestion `a)` to `d)`, there is no `b)` or `c)`.
5. **2023-E1 Q5c / 2024-Ex Q5c** ask whether the grammar of a PDA language is
   "context-sensitive". Every context-free language is also context-sensitive, so
   the expected answer needs care, see the note at `TC-06`.

## Maintenance

- Adding an item: append it to the relevant pool file with the next free ID and
  tag it `new`. Do not renumber.
- After an exam: add the exam's tag to every item used, so the reuse warning
  stays accurate.
- The figures come from `tools/genexam.py`; re-run it after editing that script.
- The solution files in `Solutions/` are generated from the pool files by
  `tools/gensolutions.py`, which also holds the slide and handout references of
  every item (the `REFS` table). After editing a solution in a pool file, or
  adding an item, add its references there and re-run the script; it reports
  any item without references.
